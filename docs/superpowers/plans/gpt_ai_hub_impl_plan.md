# AI Tele-calling Hub V2 - Product Architecture & Implementation Plan

> **Version:** V2
> **Goal:** Build a production-grade, domain-agnostic AI Tele-calling Platform.
>
> This document defines the product architecture, frontend structure and implementation strategy.
>
> **Important:** This is NOT an implementation of a single orchestrator. This is a platform where customers create Departments, Process Agents and configure AI tele-calling workflows without writing code.

---

# Product Philosophy

The platform should NOT expose technical workflow builders to normal users.

The user should think:

> "I am creating a tele-calling process."

NOT

> "I am creating a workflow."

The workflow becomes an implementation detail generated by the platform.
